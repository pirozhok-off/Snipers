# Sniper Mod for Minecraft 1.20.1

'Движок' для игры "Снайперы" в майнкрафт Forge 1.20.1

## Особенности

- 🎯 Система начала и окончания игр
- 👥 Система команд (соло/командный режим)
- 🗺️ Динамическое сужение игровой области
- 🎒 Настраиваемый спавн оружия (выдача игрокам/рандом в сундуках)
- ⚙️ Настраиваемость через конфиг
- 🎰!!!КАЗИНО!!! Можно **депнуть** абсолютно все свои **алмазы** или **монеты**

### Базовая настройка

Команда `/sniper setup` установит базовые настройки: команды и скорборды, геймрулы и т.д.
